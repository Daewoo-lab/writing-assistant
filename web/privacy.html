Какие данные мы обрабатываем

  • Telegram ID и username — для идентификации аккаунта.
  • Загруженные брифы — для формирования черновика; обрабатываются на время генерации.
  • Образцы вашего стиля (если добавили) — только для подгонки стиля черновика.
  • Данные об оплате — через Payme; реквизиты карты мы не храним.

Чего мы НЕ делаем

  • Не запрашиваем и не храним ваши логины/пароли к сторонним системам.
  • Не входим в ваши аккаунты в других сервисах и ничего там не делаем.
  • Не передаём ваши тексты третьим лицам, кроме провайдера LLM для самой генерации.

Хранение и удаление

Образцы стиля хранятся, пока вы их не удалите командой в боте. Брифы не хранятся дольше, чем нужно для генерации черновика. Запрос на удаление всех данных — через поддержку.
